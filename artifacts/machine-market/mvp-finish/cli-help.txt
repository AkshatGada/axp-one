GET inspection never sends a mutation. Submit/operator commands explicitly use existing native API contracts.
The local gateway/validator must already be running under its own approved configuration. This CLI never starts or funds it.
Historical /market/ and /api/market are a separate synthetic simulator, not this native interface.
