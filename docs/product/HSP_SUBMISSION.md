# AXP × HSP submission draft

Track: Agent Payments & A2A Settlement.

AXP lets an advertiser's buying agent evaluate a conversational moment, compete
under deterministic limits and purchase one clearly labelled Sponsored placement
below an AI app's independent answer. This hackathon branch adds direct HSP
payment orchestration for each accepted insertion and a separate HSK mainnet
registry for payment-evidence commitments.

The publisher supplies the exact accepted delivery obligation. The payer approves
HSP's prepared authorization in a browser wallet, then separately approves its
submission. The Gateway executes payment. Stable order/payment identities support
recovery without duplicate purchases. Models never hold wallet keys or choose
arbitrary payment amounts or recipients.

Existing AXP foundation: campaigns, Jev fit evaluation, deterministic auctions,
publisher SDK, insertion receipts and the independent example answer.
Hackathon addition: HSP adapter/state machine, direct accounting, browser-wallet
payment inspection, mainnet evidence registry, verification and static replay.
